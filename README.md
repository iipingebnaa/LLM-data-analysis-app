# LLM-Powered Data Analysis Application

## Project Overview

For this project, I developed a data analysis application that allowed users to upload datasets, ask questions in natural language, and receive results, visualisations and explanations. The aim was to make data analysis easier without requiring users to write Python code manually.

## Development Process

I initially developed the application in Google Colab. During this stage, I encountered difficulties accessing the Streamlit application through LocalTunnel, including module-loading errors and port conflicts. I also faced challenges getting the language model to generate code that could be executed correctly.

To overcome these issues, I moved the project to GitHub and deployed it using Streamlit Community Cloud. I configured the Groq API key through Streamlit Secrets and improved the code-validation process after the application rejected some generated code. I then tested the application using questions that calculated results and generated graphs.

## Tools Used

- Python, Pandas and NumPy for data analysis.
- Streamlit for the application interface.
- Groq API for language-model integration.
- Plotly Express for visualisations.
- Google Colab for initial development and testing.
- GitHub for version control and storing project files.
- Streamlit Community Cloud for deployment.

## Challenges and Lessons Learned

The main challenges involved accessing the application from Google Colab, troubleshooting errors and validating the Python code generated by the language model. Working through these issues helped me understand API integration, debugging and application deployment.

## Conclusion

I successfully deployed the application online, where users could upload datasets, ask questions and receive analytical results and visualisations. The project gave me practical experience in developing, testing and deploying an LLM-powered data analysis application.
